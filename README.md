Description about Project:
The chatapp is a Java-based application which is designed to handle a users login and registration.
The project focuses on making sure that the user only inserts valid information, that meets a specific conditions.
This project "chatapp" is part of my Part 1 for my programming Poe.

Features of the Project:
It has a "Username Validation:" which ensures the user only inserts a Username which contains an underscore (_) and is not longer than five characters.
It has a "Password Complexity:" function which Validates that the user password is atleast eight characters long, has a Capital letter & special character.
It has a "Phone Number Validation:" which verifies the cellphone number contains the South African international code (+27) and the number is not more than 10 characters.
It has a "Automated Testing:" JUnit 5 was used to test the validation logic and ensures that the methods work as expected.
